## 阻断项

### 阻断项 1（严重）:v2 是跨包名冲突 + 降级,非升级

| 项 | 现场 | 任务书目标 |
|---|---|---|
| 包名 | `opencode` | `opencode-compressed` |
| 版本 | **2.0.18-4** | **2.0.12-3**（更低） |

目标包 payload 路径为**相对成员** `data/data/com.termux/files/usr/…`,现装包 db 记录为**绝对路径** `/data/data/com.termux/files/usr/…`;RootDir=/ 归位后两者指向同一 5 条路径:

```
/usr/bin/opencode
/usr/lib/opencode/runtime/opencode
/usr/lib/opencode/libopencode-crhandler.so
/usr/lib/opencode/pty/librust_pty_arm64_musl_patched.so
/usr/lib/opencode/pty/shim.so
```

后果: pacman 视作**新增包**（非 upgrade）→ 无主文件冲突 + 2.0.18→2.0.12 降级 + 两包同时声称拥有同一文件,db 持续 inconsistent。

### 阻断项 2:serve pid 与现场不符,v2 serve 不存在
任务书给的 7084 / 12612 **均已不存在**。现场唯一 opencode serve:

无任何 v2 serve 在跑。→ S3/S6「两个 serve pid 仍在」门禁无法按字面满足,降级为「v1 serve 12681 不重启」。

## S0 测量口径更正

S0 报的「altered=544 / missing=0」是 `pacman -Qkk` **全库**口径（RootDir=prefix 时）。
**单包 `-Qk` 才是真相**：
```
$ pacman -r /data/data/com.termux/files -Qk opencode1-compressed   (旧 RootDir)
opencode1-compressed: 13 total files, 0 missing files
$ pacman -Qk opencode1-compressed                                   (RootDir=/)
opencode1-compressed: 13 total files, 13 missing files
```
根因: db `files` 记的是**相对路径** `usr/lib/opencode1/...`，RootDir=/ 时解析到
`/usr/lib/opencode1/`（不存在），RootDir=prefix 时才解析正确。
→ RootDir 规范化后这两包路径解析必然失效；叠影内无 opencode 文件，归位段不会修复它们。

## 阻断项 4（严重）: v2 目标包 payload 指向源码树

`/data/data/com.termux/files/usr/lib/opencode/` 是 **git 源码 checkout**
（AGENTS.md / package.json / bun.lock / packages / node_modules / runtime/ …），
`libopencode-crhandler.so` 不存在。实证:
```
$ opencode --version
CANNOT LINK EXECUTABLE "opencode": library "libopencode-crhandler.so" not found: needed by main executable
```
→ **v2 现装即已损坏**；2.0.12-3 会向源码树覆盖写入 → 不能装。

## 阻断项 5: v1 -9 payload 残缺

| 版本 | 大小 | payload 文件数 | 内容 |
|---|---|---|---|
| -7（现装）| 57M | 7 | bin/opencode1 + bin/migrate + runtime/opencode + 4×.so |
| -8 | 57M | 7 | 同 -7（路径改 data/data/… 绝对成员）|
| **-9（任务书目标）** | **44M** | **3** | **bin/opencode1 + bin/migrate + runtime/opencode（4 个 .so 全缺）** |

`.INSTALL` 自身契约明写「compressed additionally ships its shim」→ -9 违背契约。

干跑验证（不安装）:
```
$ tar -xzf …-9.pkg.tar.gz -C $PREFIX/tmp …/runtime/opencode
$ …/runtime/opencode --version   →  1.18.32      ← 二进制本身可执行
（临时目录已清理）
```

wrapper `opencode1` 对 4 个 .so 全部用 `[ -f ]` 守卫兜底，且 .so 现装在盘 →
装 -9 后 v1 仍可跑；但 `pacman -U` 会先删除旧包文件 → 4 个 .so 成 orphan 被删 → v1 随后崩。
