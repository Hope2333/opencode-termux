# 装机纪律（务必沿用）：`--overwrite` 必须用等号形式

```
✗ --overwrite <路径> …        → error: could not open file …: Unrecognized archive format
                                 error: '…': cannot open package file   （路径被当包文件）
✓ --overwrite=<路径> …         → 正常逐条绑定
```
`--overwrite` 声明为 `--overwrite <glob>`（glob 型选项）。**空格形式会把后续位置参数吞掉**，
必须用 `=` 形式逐条绑定。本机两次装机（v1 -9）均采用 `=` 形式 + 精确路径、零通配。
