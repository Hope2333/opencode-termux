## Part 2 重建链改造：epoll-compat shim 战役（含重大归因纠正）

### 假设 1（LD_PRELOAD 符号插桩）— 构建并证伪
tools/epoll-shim/：interpose libc `syscall`，441→22（epoll_pwait），timespec→ms 向上取整，aarch64 内联 svc passthrough（无 dlsym 零递归）。
oscar 实测：TUI 无 shim 4410ms 崩 vs 有 shim 4373ms 崩，bun.report 签名逐字节相同 → 插桩拦不到。
**源码定谳**：bun-src checkout 恰为 34cbb9a4（工作树 clean），src/platform/linux.rs `sys_epoll_pwait2` = Rust 内联 `svc #0`（raw_syscall6），不走 libc 符号——插桩从机制上不可能生效。

### 假设 2（seccomp TRAP+模拟，内核级）— 机制全验证，但 TUI 仍崩 → 441 排除
重写 tools/epoll-shim/epoll-compat.c：seccomp-bpf 441→SECCOMP_RET_TRAP，SIGSYS handler 用 epoll_pwait 模拟，x0 写回 + pc 自校准（si_call_addr 比较，兼容 ELR 已越过/未越过两种内核行为）；保留符号插桩双保险；可选 probe 模式（TRAP 全部 ≥424/291/286，handler raw write 记录 nr 后返回 -ENOSYS）。
- 本机（6.6）selftest：T1-T4 全 PASS，T4 = 内联 svc 直发 441 ×3（真驱动 TRAP 层），插桩探针 PASS
- **oscar selftest：baseline T1 ret=-1 errno=38 / T4 ret=-38（ENOSYS 实证），带 shim T1-T4 全 PASS（200ms/100ms 精确）→ seccomp 机制在 3.18 完全成立**
- **oscar TUI：带 shim 仍 4784ms/4434ms SIGSEGV@0x0 → 441 排除**
- probe 模式跑 TUI：零命中（崩前未触碰任何 3.18 缺失 syscall）→ 崩因与 syscall 可用性无关
- 源码侧佐证：vanilla 34cbb9a4 的 bun-usockets epoll_kqueue.c **已含** has_epoll_pwait2 ENOSYS 回退门（#32490 修复在 1.4.0 内）；task-v1rebuild 的「修复前 build / 不认旗标」归因不成立
- JIT 假设：BUN_JSC_useJIT=0 → "bun:ffi requires the JIT"（opentui 依赖 FFI，JIT 不可关），此路不通

**交付状态**：shim 作为可选资产保留（机制已双内核验证、对现有路径惰性、对未来无回退门的 bun build 有真实价值），打包链接线完成；**TUI 4.5s 崩根因未解，归因需重做**（tombstone 不可用——Termux 进程崩不进 /data/tombstones；oscar 磁盘 98M 剩余装不上 strace；后续建议：解包 runtime 上 oscar 分层定位 UPX/memfd vs runtime 因素，或 ADB root 下 gserver/perf，或解码 bun.report 栈）。

## Part 3' 六族 hook 覆盖矩阵（postinst / .INSTALL 实装盘点）

矩阵本体见 docs/hook-design-proposal.md §一。摘要：
- v1 native：deb+pacman 双侧 migrate（已特征化）+ quarantine + gated serve-kill（默认 glob 2.0.[0-3] → 1.18.x 默认关）
- v1 compressed：deb 有 migrate；**pacman 缺失**（用户实测吻合）——根因是 PKGBUILD.compressed 的 post_install 从未随包（缺 install= 指令），本次补齐
- v2 native：echo 分支 + quarantine + gated serve-kill（无 migrate，正确）
- v2 compressed：零 hook（正确）
- wrapper：deb 无 postinst；pacman 显式删除全部 hook（含 system-skills）
- standalone：零 hook（冻结定位）

**本次改造（只动 v1 族）**：新增 packing/pacman/opencode1-compressed.install（install= 注入 + MIGRATE_HOOK 构建期字面量烘焙：1=opencode1 / 0=v2 零 hook 契约）+ migrate 随包 + .INSTALL bake guard。技术要点：PKGBUILD 内 post_install 函数若无 install= 指令不随包；.INSTALL 运行在安装期，构建 env 不存在，门必须是烘焙字面量（同 native 的 PKG_NAME bake 先例）。v2 族输出零变化。
