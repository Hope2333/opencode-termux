## 💬 Community & Discussions — 繁體中文

![Discussions](https://raw.githubusercontent.com/Hope2333/opencode-termux/native-android/assets/discussions-banner.svg)

聊天吹水、問答求助、點子腦洞。RC3 雙代全家族已上架：v2 native/wrapper 各 13 版 + v1 三族 1.18.30–32，全量 PKGREL=3，70 件逐筆對帳。v1（`opencode1*`）與 v2（`opencode*`）可跨代共存，雙裝不衝突。

**安裝最新版：**

```bash
pacman -S opencode            # v2 主線
pacman -S opencode1           # v1 主線
```
